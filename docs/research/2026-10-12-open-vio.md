## 실제 기록과 현재 계약

- [Flip 6 재시험](../recordings/2026-10-12-zflip6-after-optimization.md): Lost33행 모두 `currentVisualFactors=0/1`; 해당 행 Ceres·marginalization 미실행. tracker feature 중앙값53, historical eligible80, immature146.
- 같은 기록의 IMU factor609행 모두10개 수락, invalidDepthFeatures/projectionRejects0. 삼각측량 직후 삭제된 track은 이 invalidDepth 통계에 포함되지 않음.
- `src/frontend/feature_manager.cpp`: count/depth vector/triangulate가 `observations>=2 && start_frame<WINDOW_SIZE-2` 사용. WINDOW_SIZE10이므로 anchor<8.
- `src/backend/optimizer.cpp`: factor 추가·최종 landmark 검사·marginalization의 동일 목록 순서가 `para_Feature[index]` 계약. `src/frontend/initialization/initializer.cpp`, `src/backend/estimator.cpp`에도 같은 eligibility 존재.
- OLD slide: 신규 anchor10→9→8→7. 4번째 observation에서 처음 eligible. 반복 NEW slide: anchor9 관측을 지우며 최신 관측을9에 유지; observation2·eligible0 상태가 반복 가능.
- 삼각측량: homogeneous DLT 결과의 anchor depth만 양수인지 검사. 실패를 `solve_flag2`로 표시하고 `solveOdometry()`가 optimizer 전에 삭제. 정확한 순수회전도 이 경로에 해당.
- `removeFront()`는 anchor9를 지울 때 depth 변환 없음. 현 eligibility에서는 해당 anchor가 활성화되지 않아 성립하는 전제; young activation에는 재기준화 또는 depth 무효화 필요.
- `setDepth()`는 rho0을 실패로 처리. deferred track을 structural slot에 포함할 경우, solve에 참여하지 않은 unknown depth까지 실패·삭제되는 apply 경로도 수정해야 함.
- 실패 update에서 window는 이동하며 prior를 해제함. 현재 slot mapping 보호를 위한 동작; Lost 판정만 완화하여 prior를 재사용하면 잘못된 parameter 주소를 연결할 위험.

## 수정 후보와 수학 계약

- **1순위: 관측 가능한 young track 활성화.** 구조적 slot과 기하적 admission 분리. slot은 solve/apply/marginalization 동안 list 순서·인덱스 고정; 기하 admission은 finite depth·모든 view cheirality·회전 보상 parallax/conditioning·재투영 residual로 결정.
- 미지 depth slot은 factor·map·solve_flag1에 포함하지 않음. apply에서 active mask를 확인하여 미참여 unknown rho0을 실패로 바꾸지 않음. 실패 landmark의 parameter slot은 apply/marginalization 종료 전 삭제 금지.
- world 방향 `b_i=normalize(R_WC_i*r_i)`; 두 view 각 `theta=atan2(||b_i×b_j||,b_iᵀb_j)`. 순수회전의 큰 pixel 이동을 translation parallax로 세지 않음.
- bearing 기하 행렬 `A=sum(I-b_i*b_iᵀ)`. 두 view에서는 eigenvalue가 `2,1+cos(theta),1-cos(theta)`이므로 작은 각의 condition≈`4/theta²`. condition10000은 약1.15°이며 1pixel/f460≈0.125°와 동일 조건이 아님.
- 각·condition·pixel threshold는 명시된 후보값으로 고정하고 train/held-out seed 분리. OpenVINS 값·Basalt0.05m를 전화에 그대로 조합하면 5m거리/5cm이동 같은 유효 쌍도 탈락 가능.
- 재투영은 camera model에 맞춘 `fx*(x/z-u), fy*(y/z-v)` 또는 동일 의미의 normalized residual 사용. scalar focal은 비등방 K에서 정확한 pixel metric이 아님. 시작 후보는 현 tracker1px 근처를 실험하며 GT gate로 결정; 값 존재를 정확도 근거로 쓰지 않음.
- **2순위: degeneracy 보류.** 충분한 translation 없는 rank/angle 실패는 unknown으로 bounded window 동안 유지·재시도. nonfinite input·확인된 outlier·명확한 cheirality 실패는 별도 사유로 제거. 순수회전에 INIT_DEPTH를 주입하여 visual factor 수를 늘리지 않음.
- **NEW anchor 제거:** 유효 point면 `X_W=R_WC_old*(r_old*d_old)+C_W_old`, `d_new=e3ᵀR_WC_newᵀ(X_W-C_W_new)`. 더 작은 첫 후보는 해당 young depth를 unknown으로 무효화하고 다음 관측으로 다시 삼각측량. outgoing prior에 young depth가 남는지 검사 후 선택.
- **OLD anchor 제거:** unknown depth는 음수 placeholder로 point를 변환하지 않음. remaining observations를 보존하고 새 anchor에서 재시도. 유효 point는 기존 재기준화의 all-view cheirality·finite 계약 검증.
- **후속 keyframe 후보:** current mature 연결률·회전 보상 parallax를 기록하여 rotation만으로 translation keyframe이 쌓이는지 확인. RD-VIO subframe·rotation-only factor는 별도 geometry 계획과 observability 회귀를 갖춘 후 검토.
