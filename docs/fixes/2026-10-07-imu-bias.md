- 관측: `build/dev-android/divergence-observation.json`, `build/dev-android/divergence-summary.json`의 실제 Galaxy Z Flip 6·Chrome 기록
- 후보 평균 `[-0.30890298, 0.0337092, 0.0410355]rad/s`; 기존 JS 보정 이후 정지 raw gyro `0`이 body frame `[0.3089, 0.0410, -0.0337]rad/s`로 입력
- 원인: 1.5초 평균을 실제 회전과 구분하지 못한 채 매 샘플에서 상수 차감; `|bias| < 0.35` 조건은 정지 증거 불충분
- 수정 범위: `web/js/imu.js`, `tests/browser/imu-bias-contracts.test.mjs`
- 회귀 우선: 일정 회전 `0.31rad/s`가 기존 후보 조건을 통과한 뒤 정지 raw `0`을 `-0.31rad/s`로 바꾸는 동작 재현
- 변경: sensor ingress의 후보 평균 차감 삭제; 평균은 `gyroBiasCandidate`·`gyroBiasApplied:false` metadata로만 보존

- 유지: timestamp·source clock fallback·body 축·deg/s→rad/s 변환; C++/WASM·bias 임계값·smoothing 변경 없음
- 검증: 정지 raw `0`, 비영 회전, 재측정·stop 상태 metadata 회귀; 기존 clock/source 회귀·JS syntax
